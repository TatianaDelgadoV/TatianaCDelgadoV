# Sitio web de Tatiana Delgado

Landing page estática en HTML y CSS, lista para publicarse con GitHub Pages. No requiere instalación de dependencias ni proceso de compilación.

## Publicar con GitHub Pages

1. Sube `index.html`, `README.md` y la carpeta `IMAGENES` al directorio raíz del repositorio.
2. En GitHub, abre **Settings > Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama donde subiste el sitio (por ejemplo, `main`) y la carpeta `/(root)`, y guarda.
5. Espera a que finalice la publicación. GitHub mostrará la URL del sitio en la misma sección de Pages.

Conserva el nombre `IMAGENES` y los nombres de sus archivos exactamente como están: las rutas del sitio dependen de ellos y distinguen mayúsculas de minúsculas.

## Formulario de contacto

Como GitHub Pages sirve archivos estáticos y no procesa formularios en un servidor, el formulario abre WhatsApp con el nombre, correo y mensaje escritos. El visitante confirma el envío desde WhatsApp; la página no almacena esos datos.
